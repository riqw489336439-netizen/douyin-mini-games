# Douyin Mini Games

Cocos Creator 3.8.x 抖音小游戏协同开发仓库。

当前开发基线：v13 深度去同质化二次收口版。

## 六款游戏
- shadow_cat / 影子小猫：双世界影子协作
- gravity_penguin / 重力企鹅：四向重力切换
- draw_bunny / 画线兔兔：画线生成道路
- emotion_panda / 情绪熊猫：三种情绪改变机制
- paper_fox / 纸片小狐：折叠与翻面地图
- sound_dog / 声波小狗：声波显形隐藏道路

## GitHub 协同流程
- `main`：稳定基线
- `develop`：开发整合
- `feature/*`：单款游戏独立迭代
- 修改通过检查后走 Pull Request
- Cocos Creator、抖音开发者工具和真机测试结果单独记录

## 当前开发目标
1. 六款源码规范化入库
2. Web/UI/Bootstrap 继续深度去同质化
3. Cocos Creator 真实运行与灰屏排查
4. 30 关真实可玩性与可解性验证
5. 抖音 IAA、存档、前后台、真机触控测试
