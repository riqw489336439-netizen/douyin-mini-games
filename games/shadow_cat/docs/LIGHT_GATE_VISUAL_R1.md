# 光照机关视觉语义 R1

## 问题拆分
逻辑层的 `lightGates` 表示前 N 个机关需要匹配光照状态，并不是地图中的实体墙。
此前 Bootstrap 将其绘制为贯穿两个世界的竖直 `LightSeal`，视觉上容易被理解为碰撞障碍。

## 本段处理
- 删除竖直 LightSeal 表现，不改变任何碰撞/移动/关卡数据。
- 对真正受光照约束的机关添加小角标：金色表示需要亮光，蓝色表示需要暗光。
- 已完成机关不再显示光照角标，避免状态噪声。
- 教程和关卡提示同步解释角标语义。

## 协同复核额外发现并修复
`Bootstrap.interact()` 原先在 `r.changed` 时先重绘并 return；如果一次互动既激活最后一个机关又同时满足出口条件，会要求玩家再互动一次。
现在顺序改为：先尝试完成关卡，完成后立即结算；未完成时再根据 changed 重绘。

## 保持不变
- InteractionResolver 的光照判定逻辑不变。
- Core 移动/影子逻辑不变。
- 30 关 LevelData 不变。
因此本段只修正“表现语义 + 最终互动流程”，不重新定义关卡玩法。
