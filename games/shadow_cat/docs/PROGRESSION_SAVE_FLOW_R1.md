# 通关-存档-解锁链路回归 R1

## 本段拆解

### A. 进入关卡
GameFlow.startLevel:
- 请求关卡会限制在已解锁范围内。
- 创建新的 Core。
- 清理上一局结果状态。

### B. 通关结算
tryComplete:
- 先由 Core 判断出口条件。
- 计算星级。
- 写入完成记录。
- 进入 result 页面。

### C. 存档
SaveState:
- 读取异常数据时回退新存档。
- unlockedLevel 限制 1~30。
- 星级限制 0~3。
- 完成关卡只提升，不降低历史星级。

## 本轮复核结果
当前源码链路没有发现会导致 30 关外溢或异常星级进入运行态的问题。
