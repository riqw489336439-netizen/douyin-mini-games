# 影子小猫运行验收清单

当前代码层已完成 Bootstrap、触控/键盘输入、页面流转、30关数据、存档、抖音桥接基础能力。

## Cocos Creator 3.8.x 必测
- 首场景创建空节点 `App`，挂载 `ShadowCatBootstrap`。
- 预览后确认不是灰屏，首页标题、开始/关卡/教程按钮可见。
- 进入关卡后确认现实猫与影子猫同时显示，影子 Y 轴镜像运动。
- 四方向按钮和 WASD/方向键均不会在暂停状态继续移动。
- 暂停后点击继续，角色位置、关卡计时和机关状态不得重置。
- 返回首页后再次开始，按存档从已解锁关卡进入。
- 前后台切换后不应瞬间超时。

## 抖音开发者工具必测
- 首屏和关卡页无按钮遮挡、穿透、超出安全区。
- 激励广告仅由明确按钮触发，关闭/失败后仍能继续正常关卡。
- 分享不是通关、领奖、继续游戏的强制前置。
- Storage 读写异常时游戏仍能从默认新档启动。

## 真机必测
- 常见 Android/iOS 屏幕纵向显示完整。
- 连续快速点击方向按钮不会多次误触暂停/返回。
- 前后台切换、锁屏恢复、网络断开后核心单机玩法仍可继续。
- 触控热区与视觉按钮一致。

## 已发现并修复
- 暂停后“继续”曾重新调用 startLevel，导致当前关卡状态被重置；现已改为直接 resume 并移除暂停覆盖按钮。
