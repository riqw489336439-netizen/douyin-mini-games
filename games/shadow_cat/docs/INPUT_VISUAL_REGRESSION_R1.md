# 输入与机关视觉回归 R1

本轮针对真人操作路径做静态独立复核。

发现并修复：
- 全局 120ms 防连点原先覆盖移动、互动、切光，会吞掉玩家快速的合法操作；现只保留在导航/暂停类按钮，玩法操作不走全局节流。
- 机关判定坐标此前没有对应可见目标，玩家只能猜；现按 InteractionResolver 相同的 switchX 公式绘制现实/影子机关。
- 激活后机关变绿，通过重新渲染玩法页同步状态。
- 文本和按钮 Label 显式水平/垂直居中，降低不同运行环境默认对齐差异。
- Canvas 显式绑定 UI Camera 保持不变。
- 键盘补充 F=追影、L=切光，方便 Creator 调试。

复核限制：这是源码静态/逻辑回归，不等于 Cocos Creator、抖音开发者工具或真机触控已通过。下一步继续检查动态重绘、节点事件释放、连续通关与存档边界。
