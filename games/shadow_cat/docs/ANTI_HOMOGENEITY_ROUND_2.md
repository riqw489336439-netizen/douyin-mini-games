# 抖音去同质化复核 Round 2

## 依据
- 备案审核：不可重复上传同质化游戏。
- 行为规范：不得简单修改美术、视觉、UI、元素、素材后提交玩法/内容/功能基本一致或代码包高度相似的小游戏。
- 自审标准：不可重复提交游戏场景和内容高度一致的游戏。

## 本轮实质整改
1. 1-15关：镜像影子。
2. 16-20关：延迟影子，玩家动作进入队列，影子滞后执行；出口要求延迟队列清空。
3. 21-30关：光照偏移，切换明暗会直接改变影子相对现实猫的位置关系；修复旧实现每一步累加偏移导致影子快速撞边界的问题。
4. 核心逻辑增加 pendingShadowSteps / flushShadowLag，便于后续把“等待影子追上”做成明确交互。

- 已不属于单纯角色/颜色/UI换皮方向。
