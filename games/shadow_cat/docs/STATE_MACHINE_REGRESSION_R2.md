# 状态机与交互回归 R2

## 本轮发现与修复
1. 出口视觉中心原为 (275, ±150)，InteractionResolver 实际判定中心为 (260, ±155)，存在视觉与碰撞判定偏差。现统一为 (260, ±155)。
2. interact() 在机关状态 changed=true 时原先先重绘页面，随后仍继续使用旧 resolver 返回值执行完成逻辑。现 changed 后立即重绘并 return，避免新旧 UI/Resolver 状态混用；玩家完成机关后再执行一次明确的出口互动。
3. 上轮边界修复继续保留：无实际位移的撞墙输入不污染影子状态或追影队列。
