# 真人节奏模拟第 1 轮

## 目标
在已完成逻辑可解性检查后，进一步按普通玩家的观察、误操作、理解新机制和重复点击成本检查时间压力。

## 发现
- 原时间曲线在 16–20 关引入延迟影子时仍继续缩短，19–20 关延迟 2 步且存在光照机关，学习成本与倒计时方向冲突。
- 26–30 关同时存在 3+3 机关、3 个光照约束、双出口和光影偏移，60 秒属于高风险配置。
- 原三星阈值为 50%/80%，会鼓励玩家在新机制章节过度抢时间。

## 修复
- 6–10：100 秒。
- 11–15：95 秒。
- 16–18：105 秒。
- 19–20：115 秒，专门给延迟 2 步的观察与追影操作留余量。
- 21–25：100 秒。
- 26–30：90 秒。
- 三星/二星阈值调整为 65%/90%；星级不影响继续闯关。
- 后台时间继续不计入关卡计时，返回保持暂停等待玩家主动继续。

## 双方复核结论
实现侧：时间曲线不再与机制复杂度反向变化。
复核侧：逻辑可解不等于真人可过，本轮只做操作成本模型与代码路径复核；尚未在 Cocos Creator、抖音开发者工具或真机计时游玩。
