# 影子小猫去同质化第三轮

本轮目标：把核心机制差异继续落实到玩家可见、可操作、可理解的表现层，而不是只停留在数据字段和内部算法。

## 已强化
- 关卡选择页改为章节化表达：镜像基础 / 镜像进阶·追影觉醒 / 光影变位。
- 游戏内明确显示当前影子模式及对应操作提示。
- 现实世界与影子世界使用独立场景带、独立出口标记和不同视觉区域。
- 光照机关在场景中可见，不再只存在于配置值。
- 追影模式新增独立“影子追步”操作，玩家可以主动处理延迟队列。
- 光影模式切换明暗时会立即反馈影子位置变化。
- 去除关卡页锁形 emoji，改为中文“未解锁”。

## 独立复核发现并修复
1. 追影模式最初把“切换光照”按钮替换成“影子追步”，但 16-20 关仍可能包含光照机关，导致部分机关无法切换光照。现改为追影模式同时保留“互动 / 影子追步 / 切换光照 / 暂停”。
2. 11-15 关仍属于镜像规则，但原章节标题直接写“追影篇”，与实际玩法不一致。现改为“镜像进阶 · 追影觉醒”。
3. Canvas 创建后补充显式绑定 UI Camera，降低动态 UI 启动时的相机不确定性。

## 当前去同质化判断
核心层：较强。镜像、延迟追影、光照变位三类规则已经进入 Core 和实际输入路径。
表现层：中等偏强。不同章节已经有明确规则说明、独立操作和世界分区，但仍缺正式美术资源、特效、章节主题场景。
关卡层：中等。30 关有机制阶段变化，但仍需要真实可解性验证，特别是 16-20 关延迟队列与光照机关组合。

## 仍未验证
- Cocos Creator 3.8.x 实际编译与运行。
- 抖音开发者工具预览和多宿主 QA。
- Android / iOS 真机触控、安全区和性能。
- 30 关逐关真实人工可解性。
- 六款游戏最终横向代码包、页面结构、玩法结构相似度。
