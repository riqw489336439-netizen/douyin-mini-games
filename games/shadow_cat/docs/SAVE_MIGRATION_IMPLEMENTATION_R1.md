# 存档迁移实现 R1

## 本段目标
只处理 SaveState 的版本演进，不修改 GameFlow 和关卡完成逻辑。

## 当前状态
- 当前存档版本：v1
- 已有字段：unlockedLevel、bestStars、sound、vibration
- 已有数据清洗：关卡 1~30，星级 0~3

## 下一步实现
1. 增加 migrate(raw) 方法
   - 根据 version 分流
   - 旧字段转换为当前结构

2. 增加 fallback
   - JSON 损坏
   - 类型错误
   - 字段缺失
   - 超范围数据

3. 增加安全写入策略
   - 先 normalize
   - 再写入
   - 写入失败保留内存状态

## 不处理范围
- 不改变解锁规则
- 不改变星级规则
- 不改变关卡流程

## 验证场景
- v1 存档读取
- 空存档首次启动
- 损坏存档恢复
- 未来 v2/v3 迁移
