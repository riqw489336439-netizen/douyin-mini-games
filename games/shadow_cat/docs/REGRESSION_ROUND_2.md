# 影子小猫：第二轮真人路径回归

本轮关注 Cocos 编译/运行风险、生命周期、触控安全区、快速点击与 UI 渲染稳定性。

## 已发现并修复

1. **按钮背景与文字共用同一节点**
   - 风险：Graphics 与 Label 同属 UI Renderer，在部分 Creator 版本/渲染路径中可能出现覆盖或顺序异常。
   - 修复：按钮文字拆到子节点，背景 Graphics 留在父节点。

2. **前后台生命周期未接入 Cocos Game 事件**
   - 风险：抖音切后台、系统弹窗、锁屏后，逻辑层 onHide/onShow 永远不被调用。
   - 修复：接入 `Game.EVENT_HIDE` / `Game.EVENT_SHOW`；进入后台时自动暂停，回来后由玩家主动继续。

3. **快速连点可能重复执行页面切换/关卡动作**
   - 风险：双击下一关、重试、返回可能重复创建 UI 或重复切状态。
   - 修复：所有触控按钮统一加 120ms tap guard。

4. **UI 直接铺满设计分辨率，异形屏边缘风险较高**
   - 风险：小屏或可见区域变化时底部操作区更容易贴边。
   - 修复：增加 SafeContent 容器，根据 `view.getVisibleSize()` 做保守缩放，并将核心操作区整体上移。

5. **后台回来继续即时运行容易误触**
   - 修复：后台时自动切暂停页，恢复前保持暂停，不自动恢复计时/输入。

## 仍需 Creator / 抖音开发者工具 / 真机验证

- `Canvas + Camera + SafeContent` 动态创建后是否首帧稳定显示。
- iPhone 刘海/灵动岛、Android 打孔屏实际安全区。
- 120ms 连点保护在低端 Android 上的手感。
- 系统分享、广告弹窗触发 hide/show 时是否需要区分“广告返回”和“真正后台”。
- 横竖屏旋转策略是否被抖音工程配置锁定。

## 当前结论

代码级回归已覆盖本轮问题，但不能替代 Cocos Creator Preview、抖音开发者工具和真机验收。
