# 存档迁移与恢复流程 R1

## 本段目标
只处理存档可靠性，不修改通关规则和关卡逻辑。

## 当前已有保护
- unlockedLevel 限制 1~30。
- bestStars 限制 0~3。
- 异常结构恢复 fresh save。
- 三星不会被低星覆盖。

## 下一步拆分

### A 版本迁移
- CURRENT_VERSION 增加版本判断。
- 旧字段转换到新字段。
- 保留玩家历史进度。

### B 损坏恢复
处理：
- JSON 异常。
- 缺少字段。
- 类型错误。
- 空对象。

### C 用户体验
处理：
- 恢复成功提示。
- 重置提示。
- 不影响首次用户流程。

## 保持边界
本阶段不修改 GameFlow 通关、解锁、星级算法，避免存档问题和玩法问题混合。

## 验证边界
源码设计完成；真实设备存储异常测试需要在 Cocos Creator 和目标平台环境执行。
