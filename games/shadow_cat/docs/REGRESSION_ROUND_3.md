# 真人路径回归 Round 3

本轮继续按“实现方自检 + 独立复核”执行，重点覆盖极端操作和异常数据。

## 本轮发现并修复

1. 损坏存档可能带入异常关卡、星级或无关字段。
   - 修复：SaveState 统一做 normalize；关卡限制 1~30，星级限制 0~3，仅保留合法键。

2. Creator/浏览器调试环境没有 tt 时，存档完全不可验证。
   - 修复：DouyinBridge 在 tt 不可用时使用 localStorage 作为调试回退；抖音环境仍优先使用平台存储。

3. 激励视频 show/load/close/error 链路存在 Promise 长时间不返回风险。
   - 修复：增加 load->show 回退、close/error 收口、15 秒超时保护和监听清理。

4. 第一版极端模拟里的超时用例误选了无倒计时的第 1 关，无法真正覆盖超时分支。
   - 修复：复核时发现并改为第 6 关，明确验证“超时=失败、0 星、不解锁下一关”。

## 新增模拟覆盖
