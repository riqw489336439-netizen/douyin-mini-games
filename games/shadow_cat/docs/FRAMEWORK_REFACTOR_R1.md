# 母工程框架抽离 R1

本轮不再只修单点 Bug，开始把稳定逻辑变成可维护的工程边界。

## 已落地
- 新增 `ShadowLayout.ts`，集中现实/影子世界 Y 坐标、出口坐标/半径、机关半径、世界边界以及机关位置计算。
- `InteractionResolver` 改为引用统一几何源，不再自己维护一套坐标常量。

## 发现的问题
此前表现层 Bootstrap 与判定层 InteractionResolver 分别复制 `switchX`、`155/-155`、出口坐标。即使当前数值一致，后续任何一边单独调整都会再次产生“画面位置 ≠ 实际判定位置”的回归。

## 下一步
- Bootstrap 迁移到 ShadowLayout。
- Core 世界边界迁移到 ShadowLayout，避免第三份 -300/300/-250/250 常量。
- 将纯通用能力和 Shadow Cat 专属玩法分层，公共框架只复用生命周期/存档/平台/基础 UI，不复用六款游戏的核心玩法逻辑。

## 验证边界
本轮是源码架构重构与静态复核，未宣称已经通过 Cocos Creator 编译、抖音开发者工具或真机验证。
